# Mumbai DCR Checker - Revit Add-in

Automated BIM compliance and auditing engine for Revit against the National Building Code (NBC) of India and local Development Control Regulations (DCR).

## Features
- **FSI / FAR Auditing**: Instant floor space and open space calculations.
- **Fire & Safety Compliance**: Automated checking of staircase dimensions, travel distances, and egress paths.
- **In-Context Remediation**: Live-highlights non-compliant elements directly in active Revit views.

## Installation
1. Download the latest release `.dll` and `.addin` file.
2. Copy both files to `%APPDATA%\Autodesk\Revit\Addins\<Revit_Version>\`.
3. Launch Revit.

## Requirements
- Autodesk Revit (2021+)
- .NET Framework 4.8 / .NET 8 (matching your build target)
